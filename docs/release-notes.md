**ပထမဆုံး Beta version** 🎉 — iPhone လိုပဲ `ေ` ကို အရင်ရိုက်လို့ရတဲ့ Mac မြန်မာ keyboard

### ⬇️ ထည့်နည်း
1. အောက်က **`MyanmarSimpleKeyboard-*.pkg`** ကို download ဆွဲပါ
2. နှစ်ချက်နှိပ်ပါ။ *"Apple could not verify…"* ပေါ်ရင် **Done** → System Settings → **Privacy & Security** → **Open Anyway**
3. Install ပြီးရင် menu bar ကနေ **မြန်မာ (Simple)** ကို ရွေးပါ
