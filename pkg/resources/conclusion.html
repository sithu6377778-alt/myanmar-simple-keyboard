✅ ထည့်ပြီးပါပြီ

Menu bar ညာဘက်အပေါ်က keyboard icon ကိုနှိပ်ပြီး မြန်မာ (Simple) ကို ရွေးပါ။

မတွေ့ရင် — System Settings → Keyboard → Text Input → Edit… → + → Burmese → မြန်မာ (Simple) → Add။ ဒါလည်း မပေါ်သေးရင် Log out လုပ်ပြီး ပြန်ဝင်ပါ။

Choose မြန်မာ (Simple) from the input menu in the menu bar. If it isn’t there, add it in System Settings → Keyboard → Text Input → Edit… → + → Burmese, or log out and back in.
